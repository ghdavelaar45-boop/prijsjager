Over PrijsJager

PrijsJager is een Nederlandse website in ontwikkeling voor het overzichtelijk vergelijken van producten en aanbiedingen. De website is nu een werkende demonstratie: zoeken, filteren, sorteren, favorieten en vergelijken functioneren. Live winkelprijzen worden pas getoond wanneer betrouwbare productfeeds beschikbaar zijn.

PrijsJager kan in de toekomst affiliate-links bevatten. Als je via zo'n link iets koopt, kunnen wij een commissie ontvangen. Dit kost jou doorgaans niets extra.

Contact en informatie

Heb je een vraag of wil je een fout melden? Een contactadres wordt toegevoegd voordat de website officieel als vergelijkingsdienst wordt gelanceerd.

Privacyverklaring (testversie)

Deze demonstratie gebruikt geen eigen server om persoonsgegevens te verzamelen. Zoekopdrachten blijven in je browser. Favorieten worden alleen lokaal op je apparaat opgeslagen via localStorage. Er zijn in deze versie geen analytics, advertentiescripts of affiliate-trackingcodes opgenomen. De hostingprovider kan technisch noodzakelijke serverlogs verwerken volgens het eigen privacybeleid. Bij toevoeging van externe diensten wordt deze verklaring bijgewerkt.

Affiliate-vermelding

Wanneer affiliate-links worden toegevoegd, kan PrijsJager commissie ontvangen bij een aankoop via zo'n link. De demo bevat nog geen affiliate-links.

Disclaimer

Alle bedragen en productspecificaties op deze testpagina zijn fictieve demonstratiegegevens. Controleer later bij de verkoper altijd de actuele prijs, beschikbaarheid, verzendkosten en voorwaarden. Deze testversie biedt nog geen werkende prijsvergelijking tussen winkels.
